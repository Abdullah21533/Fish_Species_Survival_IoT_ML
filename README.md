# Fish Species Survival Prediction Using IoT and Machine Learning

## Overview

This repository presents our Final Year Project (FYP), which focuses on developing an intelligent aquaculture monitoring and fish survival prediction system using Internet of Things (IoT), Edge Computing, and Machine Learning technologies.

The proposed framework integrates Raspberry Pi 5, multiple environmental sensors, ThingSpeak cloud services, and advanced machine learning algorithms to continuously monitor aquaculture ponds and predict fish species survival based on real-time environmental conditions.

The system collects water quality parameters including pH, temperature, turbidity, Total Dissolved Solids (TDS), water level, and color characteristics. These measurements are analyzed using machine learning models to support intelligent decision-making, improve fish production, reduce environmental risks, and promote sustainable aquaculture practices.
